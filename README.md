# Stone Paper Scissors Game (Java)

A console-based Stone Paper Scissors game developed in Java.

## Features
- Best of 3, Best of 5, and Best of 7 match modes
- Random computer moves
- Score tracking
- Player name customization
- Winner announcement
- Invalid input handling

## Technologies Used
- Java
- IntelliJ IDEA
- Scanner Class
- Random Class

## How to Run
1. Clone this repository.
2. Open the project in IntelliJ IDEA or any Java IDE.
3. Compile and run `Main.java`.
4. Enjoy the game!
